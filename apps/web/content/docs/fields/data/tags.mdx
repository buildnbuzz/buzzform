# Tags Field

The `tags` field renders a tag/chip input for entering multiple string values.

## Schema Properties

<auto-type-table path="../../../../../../packages/form-core/src/types.ts" name="TagsField" />

## UI Options

Same as [Text Field](/docs/fields/data/text#ui-options).

## Basic Usage

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "tags",
      name: "skills",
      label: "Skills",
      required: true,
      minTags: 3,
      maxTags: 10,
    },
  ],
});
```

## Examples

### With Max Tag Length

```tsx
{
  type: "tags",
  name: "tags",
  label: "Tags",
  maxTagLength: 20,
  description: "Max 20 characters per tag",
}
```

### Allow Duplicates

```tsx
{
  type: "tags",
  name: "emails",
  label: "Email Addresses",
  allowDuplicates: true,
}
```

### Email Tags

```tsx
{
  type: "tags",
  name: "recipients",
  label: "Recipients",
  minTags: 1,
  maxTags: 10,
  description: "Press Enter to add each email",
}
```
