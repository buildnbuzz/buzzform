# Number Field

The `number` field renders a numeric input with validation constraints.

## Schema Properties

<auto-type-table path="../../../../../../packages/form-core/src/types.ts" name="NumberField" />

## UI Options

Same as [Text Field](/docs/fields/data/text#ui-options).

## Basic Usage

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "number",
      name: "age",
      label: "Age",
      required: true,
      min: 18,
      max: 120,
    },
  ],
});
```

## Examples

### With Precision

```tsx
{
  type: "number",
  name: "price",
  label: "Price",
  min: 0,
  max: 9999.99,
  precision: 2,
  step: 0.01,
}
```

### With Step Increment

```tsx
{
  type: "number",
  name: "quantity",
  label: "Quantity",
  min: 0,
  max: 100,
  step: 5,
}
```
