# Password Field

The `password` field renders a password input with optional strength criteria.

## Schema Properties

<auto-type-table path="../../../../../../packages/form-core/src/types.ts" name="PasswordField" />

## UI Options

Same as [Text Field](/docs/fields/data/text#ui-options).

## Basic Usage

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "password",
      name: "password",
      label: "Password",
      required: true,
      minLength: 8,
    },
  ],
});
```

## Password Criteria

Set strength requirements:

```tsx
{
  type: "password",
  name: "password",
  label: "Password",
  required: true,
  minLength: 8,
  criteria: {
    requireUppercase: true,
    requireLowercase: true,
    requireNumber: true,
    requireSpecial: true,
  },
}
```

## Examples

### Confirm Password

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "password",
      name: "password",
      label: "Password",
      required: true,
      minLength: 8,
    },
    {
      type: "password",
      name: "confirmPassword",
      label: "Confirm Password",
      required: true,
      validate: {
        onSubmit: {
          checks: [
            {
              type: "matches",
              message: "Passwords do not match",
              args: { other: { $data: "/password" } },
            },
          ],
        },
      },
    },
  ],
});
```
