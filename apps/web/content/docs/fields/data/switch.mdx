# Switch Field

The `switch` field renders a toggle switch for boolean values.

## Schema Properties

<auto-type-table path="../../../../../../packages/form-core/src/types.ts" name="SwitchField" />

## UI Options

Same as [Text Field](/docs/fields/data/text#ui-options).

## Basic Usage

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "switch",
      name: "notifications",
      label: "Enable Notifications",
      defaultValue: true,
    },
  ],
});
```

## Examples

### Feature Toggle

```tsx
{
  type: "switch",
  name: "darkMode",
  label: "Dark Mode",
  description: "Switch between light and dark themes",
}
```

### Required Switch

```tsx
{
  type: "switch",
  name: "consent",
  label: "I consent to data processing",
  required: true,
}
```

### Disabled Switch

```tsx
{
  type: "switch",
  name: "premium",
  label: "Premium Features",
  disabled: true,
  description: "Upgrade to unlock",
}
```
