# Date Field

The `date` field renders a date picker with optional time selection.

## Schema Properties

<auto-type-table path="../../../../../../packages/form-core/src/types.ts" name="DateField" />

## UI Options

Same as [Text Field](/docs/fields/data/text#ui-options).

## Basic Usage

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "date",
      name: "birthDate",
      label: "Birth Date",
      required: true,
    },
  ],
});
```

## With Time Picker

```tsx
{
  type: "date",
  name: "meetingTime",
  label: "Meeting Time",
  withTime: true,
  required: true,
}
```

## Date Constraints

```tsx
{
  type: "date",
  name: "eventDate",
  label: "Event Date",
  minDate: new Date().toISOString().split("T")[0], // Today
  maxDate: "2025-12-31",
}
```

## Examples

### Date Range

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "date",
      name: "startDate",
      label: "Start Date",
      required: true,
    },
    {
      type: "date",
      name: "endDate",
      label: "End Date",
      required: true,
      minDate: "{ $data: '/startDate' }", // After start date
    },
  ],
});
```

### Birthday Picker

```tsx
{
  type: "date",
  name: "birthDate",
  label: "Date of Birth",
  minDate: "1900-01-01",
  maxDate: new Date().toISOString().split("T")[0],
}
```

## Auto-Derived Validators

| Property | Validator |
|----------|-----------|
| `required: true` | `required` |
| `minDate` | `minDate` |
| `maxDate` | `maxDate` |

## Value Format

- **Without time**: `YYYY-MM-DD` (e.g., `"2024-01-15"`)
- **With time**: Full ISO datetime (e.g., `"2024-01-15T10:30:00.000Z"`)
