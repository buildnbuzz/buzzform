# Array Field

The `array` field renders repeatable fields for dynamic lists.

## Schema Properties

<auto-type-table path="../../../../../../packages/form-core/src/types.ts" name="ArrayField" />

## UI Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `addLabel` | `string` | `"Add Item"` | Label for the add button |
| `emptyMessage` | `string` | `"No items added yet."` | Message shown when no items exist |
| `rowLabel` | `unknown` | `"Item #N"` | Row header label — use `{ $data: "fieldName" }` to show a field value |
| `isSortable` | `boolean` | `true` | Enable drag-to-reorder |
| `showErrorBadge` | `boolean` | `true` | Show error-count badge in header |
| `allowDuplicate` | `boolean` | `false` | Show a duplicate button per row |
| `confirmDelete` | `boolean` | `true` | Require confirmation before deleting all items |

## Basic Usage

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "array",
      name: "contacts",
      label: "Contacts",
      minItems: 1,
      maxItems: 5,
      fields: [
        { type: "text", name: "name", label: "Name" },
        { type: "email", name: "email", label: "Email" },
      ],
    },
  ],
});

// Result: { contacts: Array<{ name: string, email: string }> }
```

## Examples

### With Row Label

```tsx
{
  type: "array",
  name: "teamMembers",
  label: "Team Members",
  rowLabel: { $data: "/name" }, // Shows name in row header
  fields: [
    { type: "text", name: "name", label: "Name" },
    { type: "text", name: "role", label: "Role" },
  ],
}
```

### With Custom Labels

```tsx
{
  type: "array",
  name: "projects",
  label: "Projects",
  ui: {
    addLabel: "Add Project",
    emptyMessage: "No projects added yet",
    isSortable: true,
    allowDuplicate: true,
    confirmDelete: true,
  },
  minItems: 1,
  maxItems: 10,
  fields: [
    { type: "text", name: "name", label: "Project Name" },
    { type: "text", name: "description", label: "Description" },
  ],
}
```

### Disable Sorting

```tsx
{
  type: "array",
  name: "steps",
  label: "Steps",
  ui: { isSortable: false },
  fields: [
    { type: "text", name: "step", label: "Step" },
  ],
}
```

### With Error Badge

```tsx
{
  type: "array",
  name: "items",
  label: "Items",
  ui: { showErrorBadge: true },
  fields: [
    { type: "text", name: "name", label: "Name", required: true },
  ],
}
```

## Data Shape

Array fields **do** contribute to form data as arrays:

```ts
// Schema
{
  type: "array",
  name: "contacts",
  fields: [
    { type: "text", name: "name" },
    { type: "email", name: "email" },
  ],
}

// Result type: { contacts: Array<{ name: string, email: string }> }
```

## Row Label with Dynamic Values

Use `{ $data: "fieldName" }` to display a field value from each row:

```tsx
{
  type: "array",
  name: "users",
  label: "Users",
  rowLabel: { $data: "/username" }, // Shows username in header
  fields: [
    { type: "text", name: "username", label: "Username" },
    { type: "email", name: "email", label: "Email" },
  ],
}
```
