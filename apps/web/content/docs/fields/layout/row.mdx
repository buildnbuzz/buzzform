# Row Field

The `row` field renders fields horizontally in a row layout.

## Schema Properties

<auto-type-table path="../../../../../../packages/form-core/src/types.ts" name="RowField" />

## UI Options

Same as [Text Field](/docs/fields/data/text#ui-options).

## Basic Usage

```tsx
const schema = defineSchema({
  fields: [
    { type: "text", name: "firstName", label: "First Name", required: true },
    { type: "text", name: "lastName", label: "Last Name", required: true },
    {
      type: "row",
      fields: [
        { type: "text", name: "firstName", label: "First Name" },
        { type: "text", name: "lastName", label: "Last Name" },
      ],
    },
  ],
});
```

## Examples

### Inline Name Fields

```tsx
{
  type: "row",
  fields: [
    { type: "text", name: "firstName", label: "First Name" },
    { type: "text", name: "lastName", label: "Last Name" },
  ],
}
```

### City and State

```tsx
{
  type: "row",
  fields: [
    { type: "text", name: "city", label: "City" },
    { type: "text", name: "state", label: "State" },
    { type: "text", name: "zip", label: "ZIP" },
  ],
}
```

### With Conditional Visibility

```tsx
{
  type: "row",
  condition: { $data: "/showAddress", eq: true },
  fields: [
    { type: "text", name: "city", label: "City" },
    { type: "text", name: "state", label: "State" },
  ],
}
```

## Data Shape

Row fields **do not** contribute to form data. They are layout-only containers.
