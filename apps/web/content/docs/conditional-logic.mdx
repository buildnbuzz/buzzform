# Conditional Logic

BuzzForm uses a declarative AST for conditional logic — no function callbacks. Conditions work for `condition`, `hidden`, `disabled`, `readOnly`, and `required`.

## Condition Types

### Boolean Literal

Simplest form — always true or false:

```tsx
{ type: "text", name: "city", disabled: true }
```

### Atomic Condition

Check a field value against a condition:

```tsx
{
  type: "text",
  name: "city",
  label: "City",
  // Only enabled when country is selected
  disabled: { $data: "/country", eq: "" },
}
```

### Array of Conditions (Implicit AND)

Multiple conditions that must all be true:

```tsx
{
  type: "text",
  name: "company",
  // Only shown when accountType is "business" AND hasLicense is true
  condition: [
    { $data: "/accountType", eq: "business" },
    { $data: "/hasLicense", eq: true },
  ],
}
```

### Explicit AND / OR

Group conditions logically:

```tsx
{
  type: "text",
  name: "details",
  // Show when role is "developer" OR "designer"
  condition: {
    $or: [
      { $data: "/role", eq: "developer" },
      { $data: "/role", eq: "designer" },
    ],
  },
}
```

### Negation

Invert a condition with `not: true`:

```tsx
{
  type: "text",
  name: "otherReason",
  label: "Please specify",
  // Show when reason is NOT "other"
  condition: { $data: "/reason", eq: "other", not: true },
}
```

## Comparison Operators

Atomic conditions support these operators:

| Operator | Description | Example |
|----------|-------------|---------|
| `eq` | Equals | `{ $data: "/status", eq: "active" }` |
| `neq` | Not equals | `{ $data: "/status", neq: "draft" }` |
| `gt` | Greater than | `{ $data: "/age", gt: 18 }` |
| `gte` | Greater than or equal | `{ $data: "/age", gte: 18 }` |
| `lt` | Less than | `{ $data: "/age", lt: 65 }` |
| `lte` | Less than or equal | `{ $data: "/age", lte: 65 }` |
| `contains` | String contains | `{ $data: "/name", contains: "test" }` |
| `startsWith` | String starts with | `{ $data: "/code", startsWith: "ABC" }` |
| `endsWith` | String ends with | `{ $data: "/email", endsWith: "@company.com" }` |

## Using $data and $context

### Referencing Form Data

Use JSON Pointer format (paths start with `/`):

```tsx
{
  type: "text",
  name: "teamName",
  label: "Team Name",
  // Only shown when role is "Manager"
  condition: { $data: "/role", eq: "Manager" },
}
```

**Path examples:**
- `/username` — root-level field
- `/address/city` — nested field in a group
- `/items/0/name` — specific array item

### Referencing External Context

Use `$context` to access data passed via `contextData`:

```tsx
const form = useForm({
  schema,
  contextData: {
    userRole: "admin",
    permissions: ["edit", "delete"],
  },
});

// In your schema:
{
  type: "text",
  name: "adminNotes",
  label: "Admin Notes",
  // Only shown for admin users
  condition: { $context: "/userRole", eq: "admin" },
}
```

## Condition vs Hidden

Both control visibility but behave differently:

| Prop | When False | Validation | State |
|------|------------|------------|-------|
| `condition` | Field unmounted | Skipped | Removed |
| `hidden` | Field hidden | Still runs | Retained |

Use `condition` when you want to completely remove the field. Use `hidden` when you want to keep the value but hide it visually.

## Examples

### Dependent Dropdowns

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "select",
      name: "country",
      label: "Country",
      options: ["US", "UK", "Canada"],
    },
    {
      type: "select",
      name: "state",
      label: "State / Province",
      options: states,
      // Disabled until country is selected
      disabled: { $data: "/country", eq: "" },
    },
  ],
});
```

### Show/Hide Based on Selection

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "radio",
      name: "contactMethod",
      label: "Preferred Contact",
      options: ["email", "phone", "mail"],
    },
    {
      type: "email",
      name: "email",
      label: "Email",
      condition: { $data: "/contactMethod", eq: "email" },
    },
    {
      type: "text",
      name: "phone",
      label: "Phone",
      condition: { $data: "/contactMethod", eq: "phone" },
    },
  ],
});
```

### Complex Conditions

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "text",
      name: "discountCode",
      label: "Discount Code",
      // Show when cart total >= 100 AND customer is not VIP
      condition: {
        $and: [
          { $data: "/cartTotal", gte: 100 },
          { $data: "/isVip", eq: false },
        ],
      },
    },
  ],
});
```

### Required Conditionally

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "select",
      name: "contactMethod",
      label: "Contact Method",
      options: ["email", "phone"],
    },
    {
      type: "email",
      name: "email",
      label: "Email Address",
      // Required only when email is selected
      required: { $data: "/contactMethod", eq: "email" },
    },
  ],
});
```

## evaluateVisibility Helper

Test conditions outside of forms:

```tsx
import { evaluateVisibility } from "@buildnbuzz/form-core";

const condition = { $data: "/role", eq: "admin" };
const formData = { role: "admin" };

const isVisible = evaluateVisibility(condition, { formData });
// true
```
