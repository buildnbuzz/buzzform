# Validation

BuzzForm has two layers of validation:

1. **Auto-derived validators** — generated from field properties like `required`, `minLength`, `min`, etc.
2. **Custom validators** — defined in the `validate` config for additional rules

## Auto-Derived Validation

Validation is automatically generated from field properties:

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "text",
      name: "username",
      required: true,      // → adds "required" validator
      minLength: 3,        // → adds "minLength" validator
      maxLength: 20,       // → adds "maxLength" validator
      pattern: "^[a-z]+$", // → adds "pattern" validator
    },
    {
      type: "number",
      name: "age",
      required: true,
      min: 18,             // → adds "min" validator
      max: 120,            // → adds "max" validator
    },
    {
      type: "email",
      name: "email",
      required: true,      // → adds "email" validator
    },
  ],
});
```

You don't need to manually specify these in `validate` — they're derived automatically.

### Validation by Field Type

| Field Type | Auto-Derived Validators |
|------------|-------------------------|
| All fields | `required` (if `required: true`) |
| `text`, `textarea`, `password` | `minLength`, `maxLength`, `pattern` |
| `email` | `email` |
| `password` | `passwordCriteria` (if `criteria` set) |
| `number` | `min`, `max`, `precision`, `step` |
| `date` | `minDate`, `maxDate` |
| `tags` | `minTags`, `maxTags`, `maxTagLength` |
| `array` | `minItems`, `maxItems` |
| `select` (hasMany) | `minSelected`, `maxSelected` |

## Custom Validation

Use the `validate` property for explicit validation rules. Checks are grouped by trigger:

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "text",
      name: "username",
      label: "Username",
      required: true,
      validate: {
        onBlur: {
          checks: [
            { type: "minLength", message: "At least 3 characters", args: { min: 3 } },
            { type: "pattern", message: "Letters and numbers only", args: { pattern: "^[a-zA-Z0-9]+$" } },
          ],
        },
      },
    },
  ],
});
```

### Validation Triggers

- `onChange` — runs when the field value changes
- `onBlur` — runs when the field loses focus
- `onSubmit` — runs when the form is submitted

## Async Validation

Use `onBlur` or `onChange` with async validators:

```tsx
{
  type: "text",
  name: "username",
  label: "Username",
  validate: {
    onBlur: {
      debounceMs: 500, // Wait 500ms after user stops typing
      checks: [
        {
          type: "usernameAvailable",
          message: "This username is already taken",
        },
      ],
    },
  },
}
```

## Cross-Field Validation

Use `{ $data: "/path" }` to reference other fields:

```tsx
const schema = defineSchema({
  fields: [
    { type: "password", name: "password", label: "Password", required: true },
    {
      type: "password",
      name: "confirmPassword",
      label: "Confirm Password",
      required: true,
      validate: {
        onSubmit: {
          checks: [
            {
              type: "matches",
              message: "Passwords do not match",
              args: { other: { $data: "/password" } },
            },
          ],
        },
      },
    },
  ],
});
```

**Important:** Use JSON Pointer format (paths start with `/`). See [Dynamic Values](/docs/dynamic-values) for details.

## Custom Validator Registry

Register custom validators globally:

```tsx
// Define your custom validator
const customValidators = {
  usernameAvailable: async (value: string) => {
    const available = await checkUsernameAvailable(value);
    return available ? true : "Username is already taken";
  },
};

// Pass to useForm
const form = useForm({
  schema,
  customValidators,
});
```

## Form-Level Validation

Add validation at the form level:

```tsx
const schema = defineSchema({
  fields: [
    { type: "text", name: "name", label: "Name" },
    { type: "email", name: "email", label: "Email" },
  ],
  validate: {
    onSubmit: {
      checks: [
        {
          type: "namesUnique",
          message: "All names must be unique",
        },
      ],
    },
  },
});
```

## Derived Validation Mode

Control when auto-derived validators run:

```tsx
const form = useForm({
  schema,
  derivedValidationMode: "blur", // or "change" or "submit"
});
```

By default, derived validators run on blur. Set this to run them on change or submit.
