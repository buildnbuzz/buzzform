# Quick Start

This guide walks you through building a real form from scratch. By the end you'll have a working sign-up form with validation, a conditional field, and typed submission data.

<Callout type="info">
  Make sure you've completed [Installation](/docs/installation) before continuing.
</Callout>

## Step 1: Define Your Schema

A `FormSchema` is a plain object with a `fields` array. Each field has a `type`, a `name`, and optional configuration:

```tsx
import { defineSchema } from "@buildnbuzz/form-core";

const schema = defineSchema({
  fields: [
    { type: "text", name: "name", label: "Full Name", required: true },
    { type: "email", name: "email", label: "Email", required: true },
    {
      type: "password",
      name: "password",
      label: "Password",
      minLength: 8,
    },
    {
      type: "select",
      name: "role",
      label: "Role",
      options: ["Developer", "Designer", "Product Manager"],
      required: true,
    },
  ],
});
```

## Step 2: Create the Form

Render the form with the shadcn registry components. The schema drives rendering and validation:

```tsx
"use client";

import { defineSchema, type InferType } from "@buildnbuzz/form-core";
import { Form, FormContent, FormFields, FormSubmit } from "@/components/buzzform/form";

const schema = defineSchema({
  fields: [
    { type: "text", name: "name", label: "Full Name", required: true },
    { type: "email", name: "email", label: "Email", required: true },
    { type: "password", name: "password", label: "Password", minLength: 8 },
    {
      type: "select",
      name: "role",
      label: "Role",
      options: ["Developer", "Designer", "Product Manager"],
      required: true,
    },
  ],
});

type FormData = InferType<typeof schema.fields>;

export function SignUpForm() {
  return (
    <Form
      schema={schema}
      onSubmit={({ value }) => {
        console.log(value);
        // value is typed as { name: string; email: string; password: string; role: string }
      }}
    >
      <FormContent>
        <FormFields />
        <FormSubmit>Create Account</FormSubmit>
      </FormContent>
    </Form>
  );
}
```

`<FormFields />` renders all fields using the `FieldRegistry` from `<FormProvider>`. Use `<FormSubmit />` for a submit button that auto-disables while submitting.

## Step 3: Add Conditional Logic

Show a field only when another field has a specific value. The `condition` property uses a declarative AST — no callbacks:

```tsx
const schema = defineSchema({
  fields: [
    { type: "text", name: "name", label: "Full Name", required: true },
    { type: "email", name: "email", label: "Email", required: true },
    {
      type: "select",
      name: "role",
      label: "Role",
      options: ["Developer", "Designer", "Manager"],
      required: true,
    },
    {
      type: "text",
      name: "teamName",
      label: "Team Name",
      // Only shown when role is "Manager"
      condition: { $data: "/role", eq: "Manager" },
      required: true,
    },
  ],
});
```

When `role` is not `"Manager"`, the `teamName` field is unmounted and removed from form state entirely.

## Step 4: Add Validation

Use the `validate` property for explicit validation rules. Checks are grouped by trigger:

```tsx
{
  type: "text",
  name: "username",
  label: "Username",
  required: true,
  validate: {
    onBlur: {
      checks: [
        { type: "minLength", message: "At least 3 characters", args: { min: 3 } },
        { type: "pattern", message: "Letters and numbers only", args: { pattern: "^[a-zA-Z0-9]+$" } },
      ],
    },
  },
}
```

## Complete Example

```tsx
"use client";

import { defineSchema, type InferType } from "@buildnbuzz/form-core";
import { Form, FormContent, FormFields, FormSubmit } from "@/components/buzzform/form";

const schema = defineSchema({
  fields: [
    { type: "text", name: "name", label: "Full Name", required: true },
    { type: "email", name: "email", label: "Email", required: true },
    {
      type: "password",
      name: "password",
      label: "Password",
      minLength: 8,
      validate: {
        onBlur: {
          checks: [
            { type: "minLength", message: "At least 8 characters", args: { min: 8 } },
          ],
        },
      },
    },
    {
      type: "select",
      name: "role",
      label: "Role",
      options: ["Developer", "Designer", "Manager"],
      required: true,
    },
    {
      type: "text",
      name: "teamName",
      label: "Team Name",
      condition: { $data: "/role", eq: "Manager" },
      required: true,
    },
  ],
});

type FormData = InferType<typeof schema.fields>;

export function SignUpForm() {
  return (
    <Form
      schema={schema}
      onSubmit={async ({ value }: { value: FormData }) => {
        await fetch("/api/signup", {
          method: "POST",
          body: JSON.stringify(value),
        });
      }}
    >
      <FormContent>
        <FormFields />
        <FormSubmit>Create Account</FormSubmit>
      </FormContent>
    </Form>
  );
}
```
