# useForm Hook

`useForm` wraps TanStack Form's `useForm` with schema-derived defaults, submit validation, and optional output transformation.

## API Reference

### UseFormOptions

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `schema` | `FormSchema` | - | Form schema for defaults and validation |
| `defaultValues` | `Partial<TFormData>` | - | Override schema-derived defaults |
| `customValidators` | `ValidationRegistry` | - | Custom validator functions |
| `contextData` | `object` | - | External data for validators and conditions |
| `enableSchemaSubmitValidation` | `boolean` | `true` | Enable schema-based submit validation |
| `derivedValidationMode` | `"submit" \| "blur" \| "change"` | `"blur"` | When to run derived validators |
| `output` | `OutputConfig` | - | Transform form output (e.g., flatten to path keys) |

All standard TanStack Form options are also supported (`form`, `id`, etc.).

## Basic Usage

```tsx
"use client";

import { defineSchema } from "@buildnbuzz/form-core";
import { useForm } from "@buildnbuzz/form-react";
import { Form, FormContent, FormFields, FormSubmit } from "@/components/buzzform/form";

const schema = defineSchema({
  fields: [
    { type: "text", name: "name", label: "Name", required: true },
    { type: "email", name: "email", label: "Email", required: true },
  ],
});

export function ContactForm() {
  const form = useForm({
    schema,
    onSubmit: ({ value }) => {
      console.log(value); // { name: string; email: string }
    },
  });

  return (
    <Form form={form} schema={schema}>
      <FormContent>
        <FormFields />
        <FormSubmit>Submit</FormSubmit>
      </FormContent>
    </Form>
  );
}
```

## Schema-Derived Defaults

`useForm` automatically extracts `defaultValue` from your schema fields:

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "text",
      name: "name",
      label: "Name",
      defaultValue: "John Doe",
    },
    {
      type: "email",
      name: "email",
      label: "Email",
      defaultValue: "john@example.com",
    },
  ],
});

const form = useForm({ schema });
// form state includes defaults: { name: "John Doe", email: "john@example.com" }
```

You can override schema defaults:

```tsx
const form = useForm({
  schema,
  defaultValues: {
    name: "Jane Doe", // Overrides schema default
  },
});
```

## Context Data

Pass external data to validators and conditions:

```tsx
const form = useForm({
  schema,
  contextData: {
    userRole: "admin",
    maxItems: 10,
  },
  onSubmit: ({ value }) => {
    // Validators can access contextData via { $context: "/userRole" }
  },
});
```

## Custom Validators

Register custom validators:

```tsx
const customValidators = {
  usernameAvailable: async (value: string) => {
    const available = await checkUsername(value);
    return available ? true : "Username is taken";
  },
  validatePromoCode: async (value: string) => {
    const valid = await validatePromo(value);
    return valid ? true : "Invalid promo code";
  },
};

const form = useForm({
  schema,
  customValidators,
});
```

Use custom validators in your schema:

```tsx
const schema = defineSchema({
  fields: [
    {
      type: "text",
      name: "username",
      validate: {
        onBlur: {
          checks: [
            {
              type: "usernameAvailable",
              message: "This username is taken",
            },
          ],
        },
      },
    },
  ],
});
```

## Submit Validation

By default, `useForm` builds a TanStack Standard Schema validator from your schema:

```tsx
const form = useForm({
  schema,
  enableSchemaSubmitValidation: true, // Default: true
});
```

This runs all validation checks on submit, including:
- Derived validators (from `required`, `minLength`, etc.)
- Custom validators in `validate.onSubmit`

Disable if you handle validation manually:

```tsx
const form = useForm({
  schema,
  enableSchemaSubmitValidation: false,
  // Add your own onSubmit validator
  validators: {
    onSubmitAsync: myCustomValidator,
  },
});
```

## Derived Validation Mode

Control when auto-derived validators run:

```tsx
const form = useForm({
  schema,
  derivedValidationMode: "blur", // or "change" or "submit"
});
```

- `"blur"` (default) — derived validators run on blur and submit
- `"change"` — derived validators run on change, blur, and submit
- `"submit"` — derived validators only run on submit

## Output Transformation

Transform nested data to flat path keys:

```tsx
const form = useForm({
  schema,
  output: { type: "path", delimiter: "." },
  onSubmit: ({ value }) => {
    // value is transformed to flat keys: { "address.city": "NYC" }
  },
});
```

See [Output Transformation](/docs/output-transformation) for details.

## Typed Usage

Get full TypeScript inference:

```tsx
import { defineSchema, type InferType } from "@buildnbuzz/form-core";
import { useForm, type UseFormOptionsWithSchema } from "@buildnbuzz/form-react";

const schema = defineSchema({
  fields: [
    { type: "text", name: "name", label: "Name", required: true },
    { type: "email", name: "email", label: "Email", required: true },
  ],
});

// Typed options
type FormOptions = UseFormOptionsWithSchema<typeof schema>;

const form = useForm({
  schema,
  onSubmit: ({ value }) => {
    // value is typed as InferType<typeof schema.fields>
  },
});
```

## External Form Instance

Create form instance outside `<Form>` for advanced control:

```tsx
export function ControlledFormDialog() {
  const [open, setOpen] = useState(false);

  const form = useForm({
    schema,
    onSubmit: ({ value }) => {
      submitData(value);
      form.reset();
      setOpen(false);
    },
  });

  return (
    <Dialog open={open} onOpenChange={setOpen}>
      <DialogContent>
        <Form form={form} schema={schema}>
          <FormContent>
            <FormFields />
            <FormSubmit>Submit</FormSubmit>
          </FormContent>
        </Form>
      </DialogContent>
    </Dialog>
  );
}
```
