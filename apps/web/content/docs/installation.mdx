# Installation

BuzzForm ships as two npm packages plus a shadcn component registry for the UI layer.

<Callout type="warning">
  The old `@buildnbuzz/buzzform` package is deprecated. Use `@buildnbuzz/form-core` and `@buildnbuzz/form-react` for new development. See the [Migration Guide](/docs/migration) for upgrading.
</Callout>

## 1. Install Packages

Install the core and React adapter packages:

```package-install
@buildnbuzz/form-core @buildnbuzz/form-react
```

### Peer Dependencies

Both packages require TanStack Form:

```package-install
@tanstack/react-form @tanstack/form-core
```

<Callout type="info">
  If you use the `array` field type, also install the drag-and-drop dependencies:
  `@dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities`
</Callout>

## 2. Add the BuzzForm Registry to Your shadcn Config

Add the `@buzzform` registry namespace to your `components.json` so you can install BuzzForm components with short names:

```json title="components.json"
{
  // ... existing config
  "registries": {
    "@buzzform": "https://form.buildnbuzz.com/r/{name}.json"
  }
}
```

This lets you run `npx shadcn@latest add @buzzform/text` instead of the full URL.

## 3. Install Field Components

Field components are delivered via the shadcn registry. They live in your codebase so you can customize them freely.

### Recommended: Install Everything

Install all field types, the form components, and a complete registry in one command:

```bash
npx shadcn@latest add @buzzform/all
```

This installs:

- `form.tsx` — Form, FormContent, FormFields, FormActions, FormSubmit, FormReset, FormMessage
- `registry.ts` — Complete field registry with all fields pre-registered
- All field components (text, email, password, textarea, number, select, checkbox, switch, radio, date, tags, row, group, collapsible, tabs, array)
- All required UI components and dependencies

<Accordions>
<Accordion title="Alternative: Install Core + Individual Fields">

If you prefer to only install the fields you need, start with the `init` package:

```bash
npx shadcn@latest add @buzzform/init
```

This installs:

- `form.tsx` — Form, FormContent, FormFields, FormActions, FormSubmit, FormReset, FormMessage
- `registry.ts` — A **template** registry with all imports commented out

Then install individual field components as needed:

```bash
npx shadcn@latest add @buzzform/text
npx shadcn@latest add @buzzform/email
npx shadcn@latest add @buzzform/select
# ... etc.
```

After installing each field, uncomment the corresponding import and entry in `components/buzzform/registry.ts`:

```ts title="components/buzzform/registry.ts"
"use client";

import type { FieldRegistry } from "@buildnbuzz/form-react";

// Uncomment the fields you've installed:
import { TextField } from "./fields/text";
import { EmailField } from "./fields/email";
// import { PasswordField } from "./fields/password";
// ... etc.

export const registry: FieldRegistry = {
  text: TextField,
  email: EmailField,
  // password: PasswordField,
  // ... etc.
};
```

</Accordion>
</Accordions>

## 4. Set Up FormProvider

Wrap your app root with `FormProvider` so all forms can access the field registry without prop drilling.

Import the `registry` from the installed BuzzForm components and the `FormProvider` from `@buildnbuzz/form-react`:

```tsx title="app/layout.tsx"
import { FormProvider } from "@buildnbuzz/form-react"; // [!code highlight]
import { registry } from "@/components/buzzform/registry"; // [!code highlight]

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <FormProvider registry={registry}>{children}</FormProvider> {/* [!code highlight] */}
      </body>
    </html>
  );
}
```

<Callout type="tip">
  The registry is just a plain object mapping field type strings to React components. You only need to include the field types your app actually uses.
</Callout>

## 5. Verify Your Install

Create a simple form to confirm everything is wired up:

```tsx
"use client";

import { defineSchema } from "@buildnbuzz/form-core";
import { Form, FormContent, FormFields, FormSubmit } from "@/components/buzzform/form";

const schema = defineSchema({
  fields: [
    { type: "text", name: "name", label: "Name", required: true },
    { type: "email", name: "email", label: "Email", required: true },
  ],
});

export function VerifyForm() {
  return (
    <Form
      schema={schema}
      onSubmit={({ value }) => {
        console.log(value); // { name: string, email: string }
      }}
    >
      <FormContent>
        <FormFields />
        <FormSubmit>Submit</FormSubmit>
      </FormContent>
    </Form>
  );
}
```

If the form renders and submits without errors, you're good to go.
